Your CI is red. Your code is fine. Your tests are flaky.

A flaky test passes and fails on the same code. Teams lose hours clicking “re-run” and start ignoring real failures. FlakeHunter finds flaky tests by re-running the suite, sends IBM Bob 2.0 to diagnose and fix each one in parallel, and keeps a fix only if it passes every verification run.

Runs real pytest on a small sample project · about 1–2 minutes

1 · Detection

The same code, run again and again. Each square is one full CI run: green if every test passed.

2 · IBM Bob diagnoses each flaky test

One Bob agent per test, running in parallel, each in its own isolated copy of the project. Bob may only edit the test file.

3 · Verification

Each fix is applied and its test file is re-run in random order. A fix is kept only if every run passes; otherwise it is reverted automatically.

4 · Proof: the whole suite again

Same number of runs as before the fixes.
